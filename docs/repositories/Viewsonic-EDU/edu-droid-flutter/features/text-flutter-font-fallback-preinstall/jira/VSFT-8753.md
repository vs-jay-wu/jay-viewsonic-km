# VSFT-8753（來源 Spike）

## Summary

Spike [Text] Windows 字體 fallback 的 metric 對應與自適應渲染

## 背景

客戶（Rush–Henrietta Central School District）使用 Amplify 課程教材（Google Slides 格式）在 IFP52 匯入 myViewBoard 後，因字體不支援導致文字框被撐大、內容超出可視範圍，影響課堂使用體驗。

## 研究目標

1. 如何確保跨平台字體一致性（跨平台能使用統一標準集字體）。例如：App 是否需要下載字體？可不可以下載？
2. 當檔案原始字體無法在跨平台支援顯示時，能自動 fallback 到 Font Metrics 相近的字體，使文字維持在原本的版面框內、全部可見。例如：用什麼指標判斷 font metrics 相近？還是有其他 fallback 方向？

## Remark — 不跑版定義

- **版面不位移**：文字實際顯示位置與大小維持原樣，不得撐大、不得溢出可視範圍，連帶不得擠壓周邊元素。
- **內容完整**：所有文字可見，不被裁切、不被遮擋。
- **閱讀體驗一致**：行數與換行位置盡量與原稿一致，避免大幅重排。
- **Finding**（未來透過 VSFT-8915 處理）。
