## Overview

當外部檔案（Google Slides / PPT）匯入 Windows 版 myViewBoard 時，若檔案原始字體於 Flutter 未支援，找其他字體 Fallback 時導致文字框被撐大、內容溢出可視範圍。

本 Story 先以「預裝外部檔案大宗使用的字體」為主，從源頭減少需要 fallback 的情境。

來源 Spike：VSFT-8753（Rush–Henrietta Central School District 使用 Amplify 課程教材 / Google Slides 匯入 IFP52 myViewBoard 跑版案例）。

## User Value

老師將外部教材匯入 myViewBoard 時，常見外部檔案能直接以原字體顯示，大幅降低文字撐大、溢出或被裁切的發生機率。

## Scope

| Phase | 項目 | 是否在本 Story 範圍 |
|---|---|---|
| Phase 1 | 預裝外部檔案大宗使用的字體（生態系最常用前 20），以減少需要 fallback 的情境 | ✅ 是 |
| Phase 2 (TBC) | 當找不到對應字體時的 fallback 機制 | ❌ 否（後續處理） |
| Phase 3 (TBC) | fallback 後的跑版（撐大 / 溢出 / 裁切）問題處理（參考 [VSFT-8898](https://viewsonic-vsi.atlassian.net/browse/VSFT-8898)） | ❌ 否（後續處理） |
| 延伸 (TBC) | [Text] 當 App 有既有支援字體，不進行 Fallback（VSFT-8917） | ❌ 否（後續處理） |

## Acceptance Criteria

| Given | When | Then |
|---|---|---|
| myViewBoard 預安裝字體完成 | 檢視已安裝字體 | **Solution：** 預裝下方「字體盤點清單」所列 20 套字體（metric-compatible 替代打底 + Slides 常見 Google Fonts 補齊），已安裝字體含該字體集且 font-family 名稱正確 |
| 一個使用「已預裝字體」的 Google Slides / PPT 檔案 | 匯入 myViewBoard 開啟 | **Solution：** 文字以原字體或其 metric-compatible 替代正常顯示，不跑版 |
| 一個使用「未預裝 / 找不到對應字體」的檔案 | 匯入 myViewBoard 開啟 | fallback 機制與跑版處理不在本 Story 範圍（留待後續） |
