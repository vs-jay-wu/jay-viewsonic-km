## 與 VSFT-9208 的關係

- VSFT-9208（Flutter 版，本 feature 主票）是 **clone 自 VSFT-9154**。
- 兩票內容（Overview / User Value / Scope / AC / 20 套字體盤點清單）幾乎相同，差別在**平台**：
  - VSFT-9154 → **Windows** 版 myViewBoard（在 Windows 預裝字體，且 Windows 本身內建 Arial / Times New Roman / Calibri / Cambria / Georgia / Comic Sans 等系統字體）。
  - VSFT-9208 → **Flutter** 版 myViewBoard（Android / IFP）。Flutter App 無法依賴作業系統系統字體，字體必須由 App 自行 bundle 並註冊 font-family。

## Overview（原文）

當外部檔案（Google Slides / PPT）匯入 Windows 版 myViewBoard 時，若檔案原始字體於 Windows 未支援，找其他字體 Fallback 時導致文字框被撐大、內容溢出可視範圍。本 Story 先以「預裝外部檔案大宗使用的字體」為主，從源頭減少需要 fallback 的情境。

## Scope（原文）

| Phase | 項目 | 是否在本 Story 範圍 |
|---|---|---|
| Phase 1 | Windows 預裝外部檔案大宗使用的字體（生態系最常用前 20），以減少需要 fallback 的情境 | ✅ 是 |
| Phase 2 (TBC) | 當找不到對應字體時的 fallback 機制 | ❌ 否 |
| Phase 3 (TBC) | fallback 後的跑版（撐大 / 溢出 / 裁切）問題處理（VSFT-8898） | ❌ 否 |

> 完整 20 套字體盤點清單與 AC 內容同 [VSFT-9208.md](VSFT-9208.md)，此處不重複。
