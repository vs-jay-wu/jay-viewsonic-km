2. 動框之後

子頁 2 · Story 2
碰框或碰暗區 → 提示消失、Panel 出現在框右側4 · 已改
⚠️ 線上 spec 是舊的
AC 4 的 When 欄仍寫「移動或縮放框」、決策 #4 寫「動框後才出現」—— 會議已改為「碰到就出現」，AC 尚未更新。照線上 spec 驗會誤報。 見 總覽 §8。
操作（四種都要試）
  1. 移動框
  2. 縮放框（拖把手）
  3. 只在框內點一下、不移動
  4. 點框外的暗區
期望
四種都要讓 Panel 出現，且提示列連同它的 ✕ 一起消失。 Panel 在框右側（短版）：6 顆題型膠囊、預設選中 True or false、 不顯示設定段、Capture 可按。
暗區那條要額外確認
點暗區不可以移動框，也不可以關閉遮罩 —— 它只讓 Panel 現身。 （框外仍 return false、不吃下觸控。）
反向
剛進遮罩、什麼都還沒碰時，Panel 必須還沒出現（AC 3，這條沒變）。
什麼都不改直接按 Capture，以是非題成立5b
期望
不需要先點任何題型，直接 Capture 就以是非題建立草稿。
框縮到 150px 就停住（且不會靜默取消）SC-12
操作
持續縮小框，寬與高分別試。
期望
觸及 150 px 該方向停止；另一個方向仍可獨立調整。
為什麼要測
這條 AC 解的是舊的「框可縮到 <2pt 並被 commit → 靜默取消」。縮到極小卻還能按 Capture 就是壞的。

4. 面板位置

子頁 2 · Story 4（純函數 PanelPlacer）
右側放不下 → Panel 翻到左側，截圖框不位移SC-7
操作
把框拖到畫面右緣，直到右側空間小於面板寬 + 24。
期望
Panel 翻到左側、間距 24 px；截圖框本身不動（讓位的永遠是 Panel）。
40px 遲滯：在臨界帶內不來回換邊SC-25
操作
接上一條，把框慢慢往回拖。
期望
要到右側空間 > 面板寬 + 24 + 40 才翻回右側。在 +24 到 +64 之間維持左側不動。
怎麼看
在臨界點附近來回微調。面板快速左右跳動就是遲滯沒生效 —— 這正是它要防的。
兩側都放不下 → overlay 在框內，維持當前側SC-26 / SC-27
操作
把框放大到左右都容不下面板，然後繼續放更大。
期望
Panel overlay 在框內、維持它當下所在那一側；不因為框變大而換邊；不自動縮小框。
框拖到上／下緣時 Panel 被推回畫面內，Cancel 永遠按得到SC-9
操作
先選擇題讓面板變長版，再把框拖到畫面最下緣，然後最上緣。
期望
Panel 往回推、貼齊畫面邊緣就停住並沿邊滑。Cancel 與 Capture 永遠完整可見且可按。
為什麼是重點
提示消失後 footer 的 Cancel 是唯一的退出入口。它被切出畫面 = 老師沒辦法離開。Android 可用高度比 Windows 少，更容易踩到。
拖曳過程中 Panel 不跟著跳（⚠️ spec 與實作不一致）SC-8
⚠️ 先讀這段
spec 與實作對這條的說法不同，兩邊都不算 bug，別直接判失敗。
  • spec SC-8：面板位置不動，放手後才以短過場重新定位
  • 目前實作：拖曳中面板整個隱藏，放手才回來 （PanelPlacer 在 isHolding && rectMoved 時 visible = false，且有測試釘住）
待 PM 裁決，見 總覽 §8 待決。
這一項實際要驗的
不論走哪一種，面板都不可以在拖曳過程中跟著框逐格移動， 放手後要停在正確位置（右側 / 左側 / overlay 依 SC-7、SC-25、SC-26 判定）。
與 SC-25 的差別
SC-8 防「拖曳中面板跟著跳」，40px 遲滯防「停在臨界點來回換邊」。兩者是不同問題，要分開看。
面板由短版長成長版的當下就避讓SC-14
操作
把框移到面板長高後會超出畫面的位置（靠近下緣），然後才選選擇題。
期望
長高的當下立即往回推，不等下一次手勢。

7. 選班三態

期望
不出現任何浮動視窗；右欄顯示名冊；Start question 可按。

期望

期望

⚠️ 已知：按下之後沒有任何回饋
API 往返期間按鈕功能上鎖住了、外觀完全沒變（setActionsEnabled 只設 isEnabled，而背景與文字色都沒有 state_enabled 分支，也沒有 spinner）。 畫面靜止不代表沒反應，別誤判成卡死。網路慢時特別明顯。 待討論，見 總覽 §8。

連點兩次不可以建出兩個班級。 防重入擋在 listener 裡而不是靠 isEnabled（後者擋不住 performClick()）。

10. 缺陷迴歸

這條分支上修過的五個，詳見缺陷紀錄
pre-start 無班級時，不顯示「請檢查網路」D1
操作
登入但不進班 → 出題 → 停在 pre-start 空狀態。
期望
畫面上沒有「Please check your internet connection and try again.」。
背景
旗標算的是「網路 AND socket」，而 socket 是進課堂才連 —— 沒有 lesson 時必然為 false，於是畫面同時說「去開一次性班級」和「請檢查網路」。
無班級但真的斷網時，仍要提示D2
操作
停在 pre-start 空狀態 → adb shell svc wifi disable。
期望
