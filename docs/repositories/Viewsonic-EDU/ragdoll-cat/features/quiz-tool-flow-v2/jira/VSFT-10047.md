## Description

> 🔄 **2026-08-25 更新**：失敗提示改為**依啟動來源分歧**（自動啟動靜默、手動才跳 snackbar），AC 18 拆成 18／18a／18b；新增 `S1-11`（Quiz Collection 無班級也可開）；**逾時上限 10 秒 → 15 秒**；新增 `S1-13`／`S1-14`／`S1-15`（登入狀態切換不重啟 Quiz Tool）；**新增** `S1-16`／`S1-16a`（自動登入的帳號要帶入預啟動）。

Scope 1 的脊椎：從「app 啟動」到「三顆按鈕可以點」之間的完整狀態機，含成功、失敗、逾時三種結果，以及「用哪一個身分啟動」、「工具開著時發生身分切換」要怎麼處理。

## 範圍

- **App 啟動自動開 toggle**：冷啟動、shell 就緒後自動開；已還原為 ON 的 session 不重跑
- **預啟動帶入自動登入的帳號**：launcher 帶入的 token、記住登入資訊、session 還原 → **以那個帳號開**，**不以訪客情境開啟**；身分還原尚未完成時預啟動停在 loading，不允許「先訪客、再切帳號」
- **toggle 三態**：載入中（軌道 shimmer，**三顆按鈕畫出但全部不可點**）→ 成功（轉為可點）→ 失敗（按鈕消失）。表達原則是「**可見＝toggle 已開，可點＝啟動成功**」
- **三按鈕入口**：Join Class / Questions / Quiz Collection；Questions 於教室連線完成前反灰；**Quiz Collection 不需要班級即可開啟**
- **訪客**：背景建立訪客教室，不開任何視窗；**登入**：不建室、不跳選班
- **登入狀態切換不重啟**：工具已啟動時發生登入／登出／換帳號，**只 end lesson ＋ 取得新身分對應的 token**；toggle 維持 ON、三顆按鈕維持可點（無 shimmer、不反灰、不消失）
- **啟動失敗依來源分歧**：

- **app 自動開啟失敗** → toggle 靜靜回 OFF、按鈕消失、**不顯示任何訊息**
- **老師手動開 toggle 失敗** → **snackbar 顯示錯誤** ＋ toggle 回 OFF、按鈕消失
- **逾時 15 秒**：等同失敗，走同一條路（自動靜默／手動 snackbar）

## Acceptance Criteria

| # | Given | When | Then |
|---|---|---|---|
| 1 | 已登入且 toggle OFF | 開啟 toggle | 僅顯示三顆 ClassSwift 按鈕、不出現任何視窗，且 onboarding 卡出現於 Questions 按鈕旁 |
| 1a | toggle OFF | 開啟 toggle 且啟動尚未完成 | toggle 本體顯示 loading（軌道面 shimmer ＋微光掃過、knob 已在 ON 位置），**三顆按鈕已畫出但全部不可點**；不彈任何視窗。啟動完成後 shimmer 停止、軌道轉 primary 色、三顆按鈕轉為可點，onboarding 卡出現。載入期間上限 **15 秒** |
| 1b | toggle 正在 loading | 使用者再次按 toggle 關閉 | 無反應 |
| 2 | 訪客且 toggle OFF | 開啟 toggle | 訪客教室於背景建立、無視窗彈出，Questions 於教室連線完成前反灰、完成後可用 |
| S1-1 | app 冷啟動、使用者未做任何操作 | shell 就緒 | toggle 自動開啟並走完整啟動流程（loading → 三顆按鈕可點）；已還原為 ON 的 session 不重跑；**失敗時走 AC 18a（靜默）** |
| **S1-16** | app 啟動時 mVB 會**自動登入某個帳號** | shell 就緒、預啟動自動開 toggle | Quiz Tool **以該帳號的身分啟動**：不建立訪客教室、不跳選班。**不允許「先以訪客啟動、之後再切成帳號」** |
| **S1-16a** | 同上，但自動登入**失敗** | shell 就緒 | 依 mVB 既有的登入失敗處理；Quiz Tool **以訪客身分啟動** |
| S1-4 | 訪客教室仍在線 | 關閉再開啟 toggle | 允許**沒有 loading 階段**（同一 tick 就緒、三顆按鈕直接可點） |
| S1-11 | 尚未加入任何班級（登入或訪客皆同） | 點 Quiz Collection | **正常開啟**，顯示其原本的 empty 畫面 |
| S1-13 | **未登入**、Quiz Tool 已啟動 | 老師登入 | Quiz Tool **不重啟**：toggle 維持 ON、三顆按鈕維持可點 |
| S1-14 | **已登入**、Quiz Tool 已啟動 | 老師登出，或切換到另一個帳號 | 不重啟、toggle 維持 ON、三顆按鈕維持可點；end lesson ＋ 取得新身分對應的 token |
| S1-15 | Quiz Tool 已啟動、前一身分留有課程／名冊／題目草稿／其他已開的工具視窗 | 發生任一種身分切換 | 前一身分的課程、名冊、草稿與工具視窗**都不保留** |
| 18 | toggle OFF | **老師手動**開啟 toggle，但啟動階段發生錯誤 | 三顆按鈕消失、**以 snackbar 顯示錯誤訊息**、且 toggle 自動回到 OFF |
| 18a | app **自動**開啟 toggle | 啟動階段發生錯誤（含逾時） | 三顆按鈕消失、toggle 自動回到 OFF、**不顯示任何訊息** |
| 18b | 啟動已成功（三顆按鈕可點） | 後續流程失敗 | 維持既有處理，不觸發 toggle 回 OFF |
