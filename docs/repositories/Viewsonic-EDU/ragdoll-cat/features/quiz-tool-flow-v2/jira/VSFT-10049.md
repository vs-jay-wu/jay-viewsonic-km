## Description

**Spec：** [3. 出題與派送（Scope 1 邏輯 / Scope 2 換皮）](https://viewsonic-vsi.atlassian.net/wiki/spaces/myViewboar/pages/606765141)（見「Scope 1」段與「核心規則」）
**回歸 AC 來源：** [4. 作答頁（含 pre-start）與空狀態](https://viewsonic-vsi.atlassian.net/wiki/spaces/myViewboar/pages/606568769)
**總覽：** [Quiz Tool 啟動流程改版 — Spec](https://viewsonic-vsi.atlassian.net/wiki/spaces/myViewboar/pages/606797917/Quiz+Tool+Spec)（決策 #24、#29）

**介面完全維持現行 Setting 頁**（換皮屬 Scope 2），本張只加三條規則。這三條**是邏輯不是介面**：Scope 2 移除 Setting 頁時，它們原封不動遷移到作答頁的 pre-start 狀態。

## 範圍

- **無班級可達**：登入但還沒選班的老師可以一路走到 Setting 頁（截圖顯示、設定可改、草稿保留），不因為沒有教室被擋下或報錯
- **Start question 是上傳與派送的唯一觸發點**：Capture 只成形草稿，**不上傳、不建立題目**；按下 Start 才依序執行上傳 → 派送。按鈕在期間顯示 loading 且不可重複點
- **沒有學生就不能派題**：現場學生數為 0 → Start 反灰；**例外**：完全沒有教室時 Start 仍可按（它是現行 Setting 頁上叫出選班卡的唯一入口，反灰會死鎖）
- **反灰要說明原因**：表達方式待 UI 決定（一行說明／tooltip／Invite students 行動）

## Acceptance Criteria

| # | Given | When | Then |
|---|---|---|---|
| S1-5 | 已登入、尚未選班 | 走現行動線出題（Questions → 題型 → 截圖 → Capture） | 抵達 Setting 頁：截圖顯示於預覽、設定可改、草稿保留；不因為沒有教室而被擋下或報錯 |
| S1-8 | 已 Capture、草稿在 Setting 頁 | 按 Start question | **此時才**依序執行圖片上傳與題目送出；按鈕在期間顯示 loading 且不可重複點；成功後進入作答頁。Capture 到 Start 之間**不進行任何上傳** |
| S1-6 | 在 Setting 頁 | 現場學生數為 0 | Start question 反灰不可按；有 1 位以上學生時可按。**例外**：完全沒有教室時 Start 可按（叫出選班卡） |
| S1-7 | Start question 因 0 學生反灰 | — | 畫面同時說明為什麼不能按、以及下一步怎麼做（形式待定） |
| 9 | 選班卡顯示中 | 按 Enter class（或 one-time Start now） | 該按鈕轉 spinner、卡片內容與尺寸不變且暫不可互動；進班完成後卡片關閉，回到出題設定畫面（**不自動派題**） |
