## Panel 位置規則

**前提：Panel 為浮動元件，截圖框不主動位移。**

**A. 左右**（依序判斷，第一條成立就停）

1. `框右邊緣 + Panel 寬 + 24 ≤ 視窗寬` → 放**右側**，間距 24 px
2. `框左邊緣 − Panel 寬 − 24 ≥ 0` → 放**左側**，間距 24 px
3. 左右皆不符合 → **overlay 在框內，維持當前所在側**

**防抖動**：右→左門檻是 `< W+24`，左→右是 `> W+24+40` —— 兩個門檻**刻意不對稱**。

**B. 上下**（一律套用）：垂直對齊框中線，**碰到畫面上下緣就往回推**。允許壓在標題列／工具列上，但**不允許任何一部分落在畫面外**。

> A 組只改 x，沒有任何一條會動到 y。把面板拉出畫面的正是「對齊框中線」本身 —— B 不能省。
