## Description

Scope 2。pre-start 右欄 0 學生時的空狀態，以及**什麼時候會自動彈出取得班級／Join Class 的視窗**。

**平台**：Android

⚠️ 本票依 **Figma 流程圖**實作（子頁 3 有 12 個 node 對照）。尺寸／色值一律以 Figma 為準。

## 一、進場時要不要自動彈視窗

抵達 pre-start 的那一刻，依兩個問題決定：`In lesson?`（有沒有已進班的教室）與 `>=1 student joined?`。**只有一種情況會自動彈。**

| 有沒有教室 | 現場學生 | 自動出現的視窗 | 右欄顯示 |
|---|---|---|---|
| 有 | 1 位以上 | **沒有** | 學生名冊 |
| 有 | **0 位** | **join class 面板**（右側）自動出現 | 空狀態：**Waiting for students to join…** ／ Share the class link so your students can join. |
| **沒有** | — | **沒有** —— 不自動彈任何視窗 | 空狀態：**No students yet** ／ Start a one-time class, or pick one you’ve already made. ＋ **One-time class**／**My classes** 兩顆按鈕 |

「沒有教室」不自動彈，是因為此時老師還有一個系統替他決定不了的選擇（一次性班級 vs 既有班級）；自動彈出任一個都是替他做決定，而且他一關掉就沒有路走了。

## 二、兩顆按鈕觸發什麼

| 老師按 | 出現什麼 |
|---|---|
| **One-time class** | 直接起一次性班級，**join class 面板**出現（班級碼／QR）；右欄轉為「Waiting for students to join…」 |
| **My classes** | **選班卡**出現，內容依老師有沒有班級分兩種（見下） |

## 三、選班卡的兩種狀態（`my classes == 0?`）

| 狀態 | 清單區 | 主要行動 | 底部 |
|---|---|---|---|
| **一個班級都沒有** | Google Classroom icon ＋「Open myViewBoard Hub in your browser to import your Google Classroom roster.」 | **Open myViewBoard Hub**（實心主按鈕）。**沒有 Enter class** —— 沒有東西可以進 | 分隔線「Or」＋ **One-time class · Start now** |
| **有班級** | 班級清單（班名＋人數，預設選中第一個） | **Enter class**（實心主按鈕） | 同上 |

兩種狀態共通：卡片標題 **Quiz Tool**、organization 下拉（Default organization）、右上 **✕**、區段標題 **My classes**。**不論有沒有班級，一次性班級永遠是備援出口** —— 這是「按了 My classes 才發現自己沒有班」時不會走進死路的原因。

## 四、進班之後與學生加入之後

| 事件 | 畫面 |
|---|---|
| 選班卡按 **Enter class** | 進班完成後**換成 join class 面板**；右欄「Waiting for students to join…」。**不自動派題** |
| **第 1 位學生加入** | **join class 面板不自動關閉**、位置不動；右欄由空狀態轉為名冊；Start question 轉為可按 |

## 五、空狀態的視覺

icon ＋ 標題 ＋ 說明文字（＋按鈕，視變體而定）。**不使用骨架卡** —— 匿名骨架卡只留在「進行中」狀態。

> ⚠️ **文案刻意與 Figma 分歧**：設計稿寫的是 `No student yet`（單數），**實作與翻譯一律用** `No students yet`（複數）。這句會進 41 個語系，已定案以 spec 為準；需回頭請設計改稿。
