## Description

Scope 2。**Setting 頁移除**，作答頁往前延伸出一個派題前的 **pre-start 狀態**。

**平台**：Windows（whiteboard mode 與 desktop mode 皆須涵蓋）

## 一句話

**pre-start 就是進行中的畫面，只是還沒開始。**

## 版面：與進行中完全一致

| 元素 | pre-start | 派題後（進行中） |
|---|---|---|
| 題型摘要 chip | 顯示 | 相同 |
| **題目縮圖** | **顯示** | 相同 |
| **Options 選項卡** | **顯示** | 相同 |
| 右欄 Responses 標頭、Refresh、計數 | 顯示，計數 0 / 0 | 相同，隨作答更新 |
| **計時器** | 顯示，**00:00 未起跑** | 相同位置，**開始計時** |
| **右欄內容** | 0 人時**空狀態**；有人時名冊 | 學生名冊 |
| **主要按鈕** | **Start question** | **Stop submissions** |

**只有三處不同**：主要按鈕、計時器是否走動、右欄是空狀態或名冊。**不得為 pre-start 另做版面或隱藏任何既有元素。**

> ⚠️ 這推翻了先前 POC 的做法（大碼錶取代題目縮圖、移除 Options 與 header 計時器）—— 該做法**已作廢**（子頁 4 決策 #27 反轉）。票名裡的「碼錶」指的是**同一個計時器停在 00:00**，不是換版面。

## Start question 是唯一的觸發點

| 時機 | 發生什麼 |
|---|---|
| Capture 完成 | 題目草稿成形，畫面前進到 pre-start。**不上傳圖片、不建立題目** |
| 按 Start question | **這一刻才**依序執行圖片上傳 → 題目送出 |

按下後主要按鈕內 loading、期間不可重複點；失敗留在原畫面＋toast，草稿完整可重試。

## 主要按鈕：兩種語意，只有一邊有條件

| 狀態 | 按鈕 | 可用性 |
|---|---|---|
| pre-start | **Start question** | **沒有學生加入前反灰**（不論有無教室）—— Scope 1 的「無教室例外放行」**取消** |
| 進行中 | **Stop submissions** | **恆可按**，不看學生數、不看是否曾有學生、不看有無作答資料 |

Start 設條件是因為它會產生一份沒有人作答的結果；Stop 是「結束」不是「送出」，擋住只會把老師鎖在他想離開的狀態裡。

## 其他行為

- **✕** → 跳 **Discard this question?** 確認框；確認才關閉面板回工具列，取消則留在 pre-start、草稿完整
- **派題完成** → 同一面板**原地**轉為進行中（計時器開跑、位置零移動、**不重新掛載**）
