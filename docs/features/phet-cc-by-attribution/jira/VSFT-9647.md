## Description

**Feedback**
承 PhET CC-BY 合規需求：播放含 PhET activity 的副本時需顯示官方 CC-BY 歸屬標註。分工調整為：.olf 不再打包 attribution key、app 不再讀 key，改由播放端直接處理並呈現固定的英文官方標註。

**Business Value**
播放端直接呈現合規標註，讓課堂實際播放的 PhET activity 一律帶正確 CC-BY 標註，閉環合規、降低法律風險；免去 editor 打包與 app 讀 key 的鍷路。

**Solution Scope**

- 播放 PhET activity 時，播放端直接呈現固定英文官方 CC-BY 標註（不從 .olf 讀 key）：Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY 4.0 (https://phet.colorado.edu).
- 不處理 i18n，一律英文
- 於 PhET activity 左上方呈現，字級 10，樣式依 UXUI 標註元件規格
- 播放時標註維持可見：不可被其他物件覆蓋、不被裁切或移動
- 播放時標註需與背景維持足夠對比，清晰可辨
- 標註文字中的連結可點擊，以 external browser 開啟

**Remark**

- 分工調整：.olf 不再打包 attribution key、app 不讀 key；播放端直接處理呈現。
- 僅適用 2026/3/29 前發布之 historical 模擬（CC BY 4.0）。
- PhET 官方字串僅可翻譯、其他修改不允許；本票統一英文。
- 同平台對應票：[VSFT-9648](https://viewsonic-vsi.atlassian.net/browse/VSFT-9648)（mVB Windows）內容一致。
