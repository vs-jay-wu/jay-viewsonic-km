## Description

**User Story**
身為在 Hub Slide Editor 內加入 PhET 模擬的內容編輯者，我希望編輯器自動依 Hub 當下語言將 CC-BY 歸屬標註定版並打包進 .olf，以便副本被派送到任何播放端時都自帶合規標註，我不需要手動處理授權文字。

**Background**
PhET 於 2026/3 由 CC BY 改為 CC BY-NC，內容需在使用處明確標註來源。目前合規缺口：PhET activity 副本雖能打包進 .olf，但來源標註沒有內嵌進副本，播放端無從取得。

本票範圍僅限 editor 端的資料產生與打包。**editor 不在 canvas 上渲染標註文字，使用者在編輯階段看不到該文字。** 標註的視覺呈現（位置、字級、對比度、不可被遮擋、連結點擊行為）全部由播放端負責，見 [VSFT-9647](https://viewsonic-vsi.atlassian.net/browse/VSFT-9647)、[VSFT-9648](https://viewsonic-vsi.atlassian.net/browse/VSFT-9648)。

**Business Value**
把標註內嵌進 .olf 副本，讓合規責任落在內容產生點（single source of truth）：副本一旦帶出即自帶標註，消除 PhET / CC-BY 合規缺口、降低法律風險，後續任何播放端都不需重新拼裝標註。

**Solution Scope**

- 建立 PhET activity 時，editor 依 Hub 當下語言決定歸屬標註字串並定版，僅支援中／英兩種：
  - EN：Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY 4.0 (https://phet.colorado.edu).
  - ZH：模擬由 PhET Interactive Simulations, University of Colorado Boulder 提供，依 CC BY 4.0 授權 (https://phet.colorado.edu).
  - Hub 語言為中／英以外時，fallback 為英文版。
- editor 不在 canvas 顯示標註文字，使用者在編輯階段看不到、也不需操作它；標註不作為可見物件存在於編輯畫面。
- 產生播放端可讀取的 attribution 資料，並打包進 .olf 的 PhET activity 副本，隨副本一起帶出（不再只存在編輯器 runtime）。
- attribution 資料需含已定版的文字內容與其語言標記，資料形狀需與播放端解析一致（POC 格式見 Remark）。
- 語言於建立／儲存當下定版，之後不隨 Hub 語言變更、也不隨派送對象而改變。

**Remark**

- 分工（已依 refinement 修正）：本票 = editor 端定版語言、產生 attribution 資料、打包進 .olf；標註之視覺呈現與互動 = 播放端票 [VSFT-9647](https://viewsonic-vsi.atlassian.net/browse/VSFT-9647)（mVB Flutter）／ [VSFT-9648](https://viewsonic-vsi.atlassian.net/browse/VSFT-9648)（mVB Windows）。因 editor 不渲染標註，原先本票內「左上方位置、字級 10、鎖定元件不可編輯／移動、canvas 維持最上層不被遮擋」等視覺需求已移除，改由播放端票承接。
- i18n 範圍：僅中／英兩種語言，且僅在 Hub（editor）端處理；app 端不處理 i18n，只如實呈現 .olf 內字串。
- 語言定版之預期行為：同一份 .olf 一旦帶出，標註語言即固定，之後派送給語言環境不同的使用者也不會變動。此為預期行為，非 bug。
- PhET 官方規定（已查證 historical 模擬授權頁）：本字串為官方指定之歸屬文字，僅可翻譯、其他修改不允許；標註須盡可能靠近使用點並人類可讀。品牌條款另要求歸屬文字中須完整包含「PhET Interactive Simulations, University of Colorado Boulder」與該 URL，故中文版保留品牌名與 URL 之英文原文、其餘敘述譯為中文。
- POC 產出格式（供資料形狀參考，最終格式需與播放端一併定案）：attribution 為 segments 陣列，各段含 text，可選帶 url。

```json
"attribution": {
  "segments": [
    { "text": "模擬由科羅拉多大學波德分校 PhET Interactive Simulations 提供（" },
    { "text": "https://phet.colorado.edu/", "url": "https://phet.colorado.edu/" },
    { "text": "），依 " },
    { "text": "PhET 服務條款", "url": "https://phet.colorado.edu/en/licensing/html" },
    { "text": " 以 CC-BY 4.0 授權 | " },
    { "text": "隱私政策", "url": "https://phet.colorado.edu/en/licensing/html#agreement-IV" }
  ]
}
```

- 待確認（open item）：上述 POC 字串與本票 Solution Scope 之中文定稿字串不一致。經比對 PhET 官方授權頁，本票版本為官方指定字串，POC 版本因加入額外連結、改寫授權說法並中譯品牌名，屬官方不允許之 modification。建議以本票版本為準，POC 字串不採用，僅參考其 segments 資料結構。
- 待確認（open item）：[VSFT-9647](https://viewsonic-vsi.atlassian.net/browse/VSFT-9647) / [VSFT-9648](https://viewsonic-vsi.atlassian.net/browse/VSFT-9648) 現有敘述提及「樣式對齊 editor 產出」，惟 editor 已確認不渲染標註，該對照基準失效，需由 UXUI 提供標註元件規格（含對比度做法）供兩平台共用。
- 待確認（open item）：2026/3/29 之後發布之 PhET 模擬適用 CC BY-NC，非本票範圍，Hub 之收錄／阻擋策略需另案處理。
