## Description

> 內容與 [VSFT-9647](https://viewsonic-vsi.atlassian.net/browse/VSFT-9647)（mVB Flutter）一致，僅平台不同（mVB Windows / sparrow）。

**User Story**
身為使用 mVB app 播放含 PhET 副本的老師，我希望播放端讀取 .olf 內嵌的 CC-BY 合規標註 key 並如實呈現且清晰可辨，以便課堂上派發的副本符合 PhET 使用規範。

**Feedback**
承 [VSFT-9586](https://viewsonic-vsi.atlassian.net/browse/VSFT-9586)：editor 已將 CC-BY 標註（含已定版語言之字串）打包進 .olf 副本。目前播放段未有 PhET 規範的標註文字，不符合使用規範。

**Business Value**
播放端讀 key 並呈現，讓 .olf 副本在課堂實際使用時可見合規標註，閉環 PhET / CC-BY 合規，對外派發無法律風險。

**Solution Scope**

- 播放 PhET activity 時，讀取 .olf 內嵌的 CC-BY 合規標註 key
- 如實逐字呈現 .olf 內已定版的標註字串（可能為中文或英文，由 Hub editor 於建立時依 Hub 語言定版）；app 端不做語言判斷、不做 i18n、不重新翻譯
- 於 PhET activity 左上方呈現，字級 10，樣式對齊 editor 產出
- 播放時標註維持可見：不可被其他物件覆蓋、不被裁切或移動
- 播放時標註需清晰可辨識：與其後方背景維持足夠對比，不因背景色與文字色衝突而無法辨識
- 標註文字中的連結可點擊，並以 external browser 開啟
- 舊版副本無此 key 時的 fallback 行為（不顯示 / 不報錯）

**Remark**

- i18n 分工：語言在 Hub（editor）端決定並於建立／儲存時定版（僅中／英兩種）；app 端不處理 i18n，只如實呈現 .olf 內字串。app 介面語言與 .olf 內字串語言不同時，一律以 .olf 內字串為準，此為預期行為、非 bug。
- 字串為 PhET 規範文字，僅適用 2026/3/29 前發布之 historical 模擬（CC BY 4.0）；依 PhET 官方規定，歸屬文字僅可翻譯、其他修改不允許，且須盡可能靠近使用點並人類可讀。
- 相依 [VSFT-9586](https://viewsonic-vsi.atlassian.net/browse/VSFT-9586)（需其打包的 key 格式與已定版字串）。
- 同平台對應票：[VSFT-9648](https://viewsonic-vsi.atlassian.net/browse/VSFT-9648)（mVB Windows，內容一致）。
- 舊 app 相容性可參考 [VSFT-9531](https://viewsonic-vsi.atlassian.net/browse/VSFT-9531)。
- attribution 為 segments 陣列，播放端依序串接各段 text 呈現；帶 url 的段落需渲染為可點擊連結。

**顯示文字：Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY 4.0 ([https://phet.colorado.edu](https://phet.colorado.edu) )**

## Acceptance Criteria

| Given | When | Then | Remark |
| --- | --- | --- | --- |
| .olf 副本內含英文版 PhET CC-BY 標註 key | 於 app 播放該 PhET activity | 於 activity 左上方逐字呈現（字級 10）：Simulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY 4.0 (https://phet.colorado.edu). | 樣式對齊 editor 產出；文字需逐字一致，不重新翻譯。此為 PhET 官方指定字串 |
| .olf 副本內含中文版 PhET CC-BY 標註 key | 於 app 播放該 PhET activity | 於 activity 左上方逐字呈現（字級 10）：模擬由 PhET Interactive Simulations, University of Colorado Boulder 提供，依 CC BY 4.0 授權 (https://phet.colorado.edu). | 即使 app 介面語言為英文，仍依 .olf 內字串呈現；app 不做語言切換。品牌名與 URL 依 PhET 品牌規範保留英文原文 |
| 標註文字中含可點擊連結（例如 https://phet.colorado.edu） | 使用者於播放中點擊該連結 | 以 external browser 開啟該連結，不在 app 內以嵌入式視窗開啟 | 連結數量依最終採用之字串定案；全螢幕授課中之切換體驗見 Remark open item |
| 播放中的 PhET activity 已顯示標註 | 其他物件或互動元素疊加至該區域 | 標註維持可見，不被覆蓋/裁切/移動 | 對應 [VSFT-9586](https://viewsonic-vsi.atlassian.net/browse/VSFT-9586)「不可被遮擋」的播放端保證 |
| PhET 模擬背景為深色、淺色，或播放中背景發生變化 | 標註呈現於該背景之上 | 文字與背景維持可辨識對比（建議 ≥ 4.5:1，比照 WCAG AA 小字），必要時以襯底或描邊確保辨識 | 不因背景色與文字色衝突而無法辨識；需在 IFP 實際投影距離下可讀 |
| 舊版 .olf 副本無合規標註 key | 於 app 播放該 activity | 不顯示標註且不報錯（graceful fallback） | 避免舊內容播放異常 |
