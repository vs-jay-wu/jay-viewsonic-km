3. Background

  • PhET 於 2026/3/29 起將新發布模擬的授權由 CC BY 4.0 改為 CC BY-NC；之前發布的 historical 模擬維持 CC BY 4.0。
  • CC BY 要求：內容需在使用處明確標註來源（attribution），須「盡可能靠近使用點並人類可讀」。
  • 目前合規缺口：PhET activity 副本能打包進 .olf，但來源標註沒有內嵌進副本，播放端無從取得、也未顯示 → 課堂派發的副本不符 PhET 使用規範。
  • 依 PhET 官方規定：歸屬文字僅可翻譯、其他修改不允許；品牌條款要求完整包含「PhET Interactive Simulations, University of Colorado Boulder」與官網 URL。
  • editor 不在 canvas 渲染標註（編輯階段看不到）；視覺呈現全由播放端負責 — 這是 refinement 後的分工修正。

4. Solution Scope（VSFT-9647，mvbf 播放端）

  • 播放 PhET activity 時，讀取 .olf 內嵌的 CC-BY 合規標註 key。
  • 如實逐字呈現已定版字串（中或英，由 Hub editor 建立時定版）；app 端不做語言判斷、不 i18n、不重新翻譯。
  • 於 PhET activity 左上方呈現，字級 10。
  • 播放時標註維持可見：不可被其他物件覆蓋、不被裁切或移動。
  • 與背景維持足夠對比（建議 ≥ 4.5:1，WCAG AA 小字），必要時襯底或描邊；需在 IFP 投影距離下可讀。
  • 標註內連結可點擊，以 external browser 開啟（不用 app 內嵌視窗）。
  • 舊版副本無此 key → graceful fallback：不顯示、不報錯。

5. 定版字串（PhET 官方指定，僅可翻譯）

語言字串（逐字呈現）
ENSimulation by PhET Interactive Simulations, University of Colorado Boulder, licensed under CC BY 4.0 (https://phet.colorado.edu).
ZH模擬由 PhET Interactive Simulations, University of Colorado Boulder 提供，依 CC BY 4.0 授權 (https://phet.colorado.edu).
其他Hub 語言非中／英 → fallback 英文版
語言於建立／儲存當下定版，之後不隨 Hub 語言或派送對象改變。app 介面語言與 .olf 字串語言不同時，一律以 .olf 字串為準（預期行為、非 bug）。

6. attribution 資料格式（POC，未定案）

VSFT-9586 Remark 給出的 POC 形狀：attribution 為 segments 陣列，各段含 text、可選 url；播放端依序串接呈現，帶 url 的段落渲染為可點擊連結。

"attribution": {
  "segments": [
    { "text": "模擬由科羅拉多大學波德分校 PhET Interactive Simulations 提供（" },
    { "text": "https://phet.colorado.edu/", "url": "https://phet.colorado.edu/" },
    { "text": "），依 " },
    { "text": "PhET 服務條款", "url": "https://phet.colorado.edu/en/licensing/html" },
    { "text": " 以 CC-BY 4.0 授權 | " },
    { "text": "隱私政策", "url": "https://phet.colorado.edu/en/licensing/html#agreement-IV" }
  ]
}
Open item（VSFT-9586）：POC 字串與官方定稿字串不一致 — POC 版加入額外連結、改寫授權說法並中譯品牌名，屬 PhET 不允許之 modification。票上建議：字串以官方版為準，POC 僅參考 segments 資料結構。最終 key 名稱、位置（html-activity 層級）與語言標記欄位需與播放端一併定案 — 目前 OLF 規格頁（v7）尚未定義 attribution key（見 findings）。

9. Open Questions

  • key 格式未定案：OLF 規格頁 v7 無 attribution 定義；segments 結構、key 名稱、語言標記欄位需 editor 與兩播放端一併定案（VSFT-9586 open item）。
  • UXUI 規格缺口：票上「樣式對齊 editor 產出」已失效（editor 不渲染標註），需 UXUI 提供標註元件規格（含對比度做法）供兩平台共用。
  • 連結點擊體驗：全螢幕授課中點連結跳 external browser 的切換體驗，連結數量依最終字串定案。
  • CC BY-NC 新模擬：2026/3/29 後發布之模擬非本案範圍，Hub 收錄／阻擋策略另案處理。
