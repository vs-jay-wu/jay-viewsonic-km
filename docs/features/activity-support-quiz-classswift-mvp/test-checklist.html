0. 測試前置設定

☑項目步驟 / 說明
裝置 & App mvbf（com.viewsonic.droid，flavor edla debug）＋ CS Android（...classswift.stag，stagDebug）皆已安裝於同一台。
登入 mvbf 用 debug_credentials.dart 帳號登入（右上角出現帳號）。未登入也可測 Story 2-2.B。
匯入測試 OLF 開啟 /sdcard/Download/mixed-activity-sample.olf。三頁：

② 多題頁（11 題，含 4 型 → Batch）

1. Story 1-1：Quiz 課件頁顯示「開始派題」CTA

☑測試點操作步驟預期結果
派題入口顯示開啟含 quiz 的 OLF，切到多題頁 / 單題頁畫布右下角出現藍色「開始派題」按鈕（activity 正下方、靠右）
入口可見性收斂切到非 quiz 頁（遊戲頁 / 空白頁）不顯示「開始派題」按鈕
UI 簡化在 quiz 頁看 activity 工具列不顯示「帳號 / 編輯 / 刪除頁面 / 解析」CTA
答案揭示點 activity 上的「答案」（多選/單選/是非題）切換為顯示正解（highlight）；簡答題不顯示「答案」鈕
Inking 不遮擋按鈕在 quiz 頁上用筆書寫，把筆畫劃過「開始派題」按鈕位置按鈕仍可點、不被筆畫蓋住（按鈕在 ink 之上；tab 底座在 ink 之下可被寫）
Prepare / Present 一致切換編輯 / 簡報模式兩模式下按鈕可見性與行為一致
單題 / 多題視覺一致分別看單題頁與多題頁的按鈕按鈕外觀一致（老師端不需感知單/多題差異）

2. Story 1-2：點擊「開始派題」觸發

☑測試點操作步驟預期結果
Toggle 觸發按鈕可點時點一下按鈕進入 disabled（單純變灰、無轉圈 spinner），同時喚起 ClassSwift toggle
派題類型決策單題頁點派題 vs 多題頁點派題單題→走 Single（create_quiz）；多題→走 Batch（batch_quizzes）
15s timeout讓喚起卡住 ≥15s（例如拔網路 / CS 無回應）顯示啟動逾時 toast + 按鈕回復可點（enabled）
失敗回復任一階段失敗（見 §7）按鈕回復 enabled + 錯誤 toast（4s 自動消失）

3. Story 2-1 ~ 2-4：喚起 / 登入 / 選班 / 派題視窗

☑測試點操作步驟預期結果
自動喚起 CSCS 未開時點「開始派題」自動喚起 CS（toggle 打開），跑 loading / OTA / token 交換，ready 後自動續派（不用再點一次）
已登入 → 選班（2-2.A）已登入 mvbf，點派題取得班級列表並引導選班 / one-time class
未登入 → 直接派（2-2.B）未登入 mvbf，點派題不取班級列表、不進選班，以 guest 直接進派題視窗（此為 Android spec 行為，與 Windows「引導登入」不同）
首次派題視窗 Path A首次派題、還沒學生加入時跳出 Join Class 視窗 + 派題視窗並列（Join Class 在最上層）；視窗位置由 CS 端控制
Join Class 顯示條件已有學生加入 vs 沒學生參考 Spinner 邏輯：有學生就不顯示 Join Class，沒學生才顯示
Late Join 不 timeoutPath A 開著、遲遲沒學生加入Join Class 視窗不自動關閉；老師可手動關或繼續等
Path B（連續派題免重 join）是 Phase 2，不在這次測試。選班本身（Story 2-3）完全沿用既有 Windows Integration 流程。

4. Story 2-5：派題後學生作答（Single / Batch）

☑測試點操作步驟預期結果
Single Dispatch（N=1）在單題頁點派題 → 學生端作答走 create_quiz；學生收到 1 題並可作答；老師端即時看到答題狀況
Batch Quiz（2≤N≤20）在多題頁點派題 → 學生端作答走 POST batch_quizzes；學生收到整批題；OPEN→FINISH→DISCLOSED 生命週期正常
共通邊界派題中最小化視窗 / 學生斷網重連 / 老師切頁派題狀態維持不中斷（沿用 Phase 0 + socket reconnect）

5. Story 3-1：題型打包（Phase 1 四型）

☑測試點操作步驟預期結果
是非題 TRUE_FALSE多題頁派題後看學生端第 7、8 題兩選項 + 正解標記正確
單選 SINGLE_SELECT看多題頁第 4~6 題 / 單題頁option_type=ALPHABET，含正解
多選 MULTIPLE_SELECT多題頁派題後找「岩質行星多選」那題多個 is_answer=true（Mercury+Mars）、option_type=ALPHABET
簡答 SHORT_ANSWER看多題頁第 1~3 題學生端顯示作答框（無正解）
混合題型同 batch多題頁一次派出同一 batch 內含不同 quiz_type，皆正常
欄位缺漏兜底（若有測資）題目缺必要欄位該題標 invalid、於該頁排除，不送 broken payload；不整批失敗

6. Story 4-1：派題期間按鈕狀態

☑測試點操作步驟預期結果
派題狀態保留派題進行中（status=OPEN）切離該頁再切回「開始派題」按鈕仍為 disabled，無法重複派
重派觸發該題已 FINISH / DISCLOSED / CLOSE 後再點按鈕直接進入新一輪派題流程
只要派題就 disable派題後不換頁 / 換到下一頁再回按鈕都維持 disable（會議補充）

7. Story 4-2：網路 / API 失敗處理

本次實作：失敗以 reason enum 表達（QuizDispatchFailure：noQuizzes / connectionLost / launchTimeout / dispatchRejected），i18n 在 widget 層。目前四種 reason 顯示同一句 toast：
en「Failed to start questions. Please try again.」/ zh-Hant「派題失敗，請再試一次。」/ zh-Hans「派题失败，请再试一次。」
☑失敗情境（reason）怎麼觸發預期結果
連線異常 connectionLostmVB↔CS IPC 中斷時點派題（或 sendMessage 失敗）顯示錯誤 toast + abort；不送 single/batch API；按鈕回復 enabled
啟動逾時 launchTimeout喚起 CS 卡 ≥15s逾時 toast + 按鈕回復 enabled
CS/後端拒絕 dispatchRejected後端回 5xx / failed（例如重複派撞到 503）顯示錯誤 toast + abort；不顯示派題進行中 UI
空題 noQuizzes（防禦）該頁過濾後無可派題目顯示錯誤 toast、不派
異常退出派題中強制關閉 mVB 再重開不主動重送；按鈕依當前派題 status 呈現

8. Story 4-3：結束派題回到簡報

☑測試點操作步驟預期結果
派題收合題目 FINISH + REVEAL/DISCLOSED 後，點 CS 端「結束派題」CS 視窗依 Phase 0 收合；CS Toggle 不會自動關閉
強制結束進行中（有學生未答完）主動點「結束派題」沿用 finish/close 轉 FINISH
按鈕復原CS 視窗收合後回到課件頁「開始派題」按鈕由 disable 轉回 enable
內容保留回到課件頁課件頁與派題前一致（含 ink、Element）

9. 額外測試（跨題型 / 多語系 / 強制亮色）

☑測試點操作步驟預期結果
多語系按鈕文案切 en / 繁中 / 簡中，看「開始派題」按鈕en「Start question(s)」/ 繁「開始派題」/ 簡「开始派题」；不 overflow(紅線)、不換行（過長會等比縮小）

卡片陰影看 activity + tab 底座整體連體卡片有一體 drop shadow（黑@20%/blur16/offset0,4）；WebView 與 tab 接縫不互相投影
按鈕隨畫布縮放縮放 / 平移畫布按鈕跟著 activity 一起縮放位移，貼齊 tab 底座

10. 已知狀況（看到別緊張，不是這次的 bug）

✅ 派題後圖片破圖 = 跨環境不支援（非 bug，與後端確認）
非 bug、非 mvbf/CS 前端問題——跨環境圖片本就不支援（預期行為）。 來源圖（media-rc.us…，RC 產）在 mvbf activity 頁正常（HTTP 200）；派題後 CS 把 img_url 改寫成 media.<派題環境>…/lesson_id_…/img/… 回 403，因為派題是 S3 同 bucket copy （非 HTTP 抓公開址），RC 來源不在 stage bucket → copy 不到。 用 RC 圖派到 stage 讀不出來是正常；同環境產題+派題即正常。詳見 findings §10。測試時此破圖不算 fail。
單題頁 vs 多題頁走不同 API
單題頁（N=1）走 create_quiz（Single），多題頁（N≥2）走 batch_quizzes（Batch）——這是預期分流，不是不一致。
投票 / 錄音題不見了？
POLL / RECORD 是 Phase 2，mvbf parser 會過濾掉不打包。這次不該出現在派題結果。

11. 快速回歸清單（5 分鐘 smoke test）

☑步驟
開 OLF → 遊戲頁不顯示按鈕、quiz 頁顯示按鈕
單題頁點派題 → 走 Single、學生收到 1 題
多題頁點派題 → 走 Batch、學生收到整批、含 MULTIPLE_SELECT
派題中按鈕 disable（切頁再回仍 disable）
CS 端結束派題 → 按鈕回 enable、回到課件頁內容不變
失敗情境（拔網路點派題）→ 錯誤 toast、按鈕回 enable
dark mode 開 quiz 頁 → 卡片與按鈕仍亮色
測試環境：Pixel Tablet（adb 3629105H804NHC）+ 學生端手機 / Playwright。 Join：s.mvb.fyi/join + CS 面板的 8 碼 Class ID（每場不同）。
