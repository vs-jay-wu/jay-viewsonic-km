🎯 調查問題（修正後）

OLF 有一個 annotation 種類是 activity，activity 又分子類（phet、game、quiz…）。 一鍵派題 focus 在 quiz。

問：哪個服務規範了 quiz 的題型？支援 audio / poll…嗎？哪些服務能產出 quiz activity？他們各自支援哪些題型？

（不是問 mvbf/Flutter 端支援什麼 — mvbf 是 pass-through，把 activity 資料轉送 ClassSwift 而已。）

📌 TL;DR

  • 唯一的 quiz activity 生產者是 african-golden-cat（ClassSwift Hub 前端 React/Vite app）。
  • Hub 前端定義 7 種 quiz_type，UI 全部都可建立/編輯（包含 RECORD）：SINGLE_SELECT、MULTIPLE_SELECT、SHORT_ANSWER、TRUE_FALSE、RECORD、SINGLE_POLL、MULTIPLE_POLL — 與 Confluence spec 完全一致。
  • 另外定義 option_type enum（4 種）：TRUE_FALSE、ALPHABET、NUMBER、NO_OPTION。
  • OLF activity category 值是 Activity_HTML_QUIZ（不是簡單的 "quiz"）；同層 sibling 有 Activity_PHET、Activity_GAME。
  • 消費端分兩個平台：
    • ClassSwift Desktop（maine-coon-cat）— 用合併 5 種 enum（MULTIPLE_CHOICE 併吞 SINGLE/MULTIPLE_SELECT；POLL 併吞 SINGLE/MULTIPLE_POLL）
    • ClassSwift Android（ragdoll-cat）— 用granular 8 種 + UNSPECIFIED（與 Hub 對齊、額外多 SKETCH_RESPONSE）
  • 對 mvbf pass-through 的好消息：CS Android enum 與 Hub 命名一致，mvbf 原封 forward Hub 的 quiz_type 給 CS Android 即可，不需 mapping。
  • 候選 repo 掃描：edu-mvb-whiteboard-ui、edu-mvb-embeddedform-ui、edu-mvb-artisan-*、edu-ui-hub-game 都沒找到 quiz activity 生產程式碼。

📋 Hub 定義的 7 種題型

來源：african-golden-cat/src/enums/quiz.ts

#quiz_type中文典型 option_type特徵
1SINGLE_SELECT單選ALPHABET / NUMBER / TRUE_FALSE多選項，只有 1 個 is_answer=true
2MULTIPLE_SELECT多選ALPHABET / NUMBER多選項，多個 is_answer=true
3TRUE_FALSE是非TRUE_FALSE / ALPHABET / NUMBER2 個選項（T/F、A/B、1/2 三種呈現）
4SHORT_ANSWER簡答NO_OPTION無選項，含 short_answer 參考解答，可 AI 判分
5SINGLE_POLL投票（單）ALPHABET / NUMBER單選投票，無正解
6MULTIPLE_POLL投票（多）ALPHABET / NUMBER多選投票，無正解
7RECORD錄音N/A語音錄音題（Hub 目前主要在 CS Desktop 播放端出現，Hub 前端 authoring 是否可建 待確認）
發現：Hub 定義的這 7 種 = Confluence spec 列的 7 種（Phase 1 前 4 + Phase 2 後 3）。 也就是說 Confluence spec 的題型清單，就是直接引用 Hub 前端的 QUIZ_TYPE enum。

🖱️ Hub UI 實際可建的題型（全部 7 種都可建）

結論：QUIZ_TYPE enum 7 種在 Hub UI 上全部可建立/編輯，包含 RECORD。 沒有「enum 有但 UI 不給建」的情況。

🎁 產全 7 種樣本 OLF 的 recipe

建議作法：GUI 產 3 種 + curl 補 4 種
  1. 先用 GUI 產 3 種（測 happy path）：
    • Hub Web → Quiz Collection → 上傳含單選/是非/簡答的 doc → AI 生題 → 存進 Collection
  2. 取 Bearer token（自己在瀏覽器 DevTools 拿，不用給我）：
    • Chrome DevTools → Network → 找任一 /quizzes/collection/* request → Headers 的 Authorization: Bearer ... 複製起來
  3. curl 打 POST /quizzes/collection/quiz 補 4 種：
    • MULTIPLE_SELECT（多選）
    • SINGLE_POLL（單投票）
    • MULTIPLE_POLL（多投票）
    • RECORD（錄音，option_type=NO_OPTION）

⚠️ zsh 陷阱

zsh 內建變數 $USERNAME 是綁定 OS user 的 read-only 變數（macOS 上等於 whoami）。
寫 script 讀 .env 的 VS_STAGE_USERNAME 時， USERNAME=$(...) 會被 zsh 忽略、變數保持為 OS user 名。改用其他變數名（如 STAGE_EMAIL）即可。
